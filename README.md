# pow-load-test

ブラウザ負荷テスト（学習・デモ用）。

PoW（Proof-of-Work）型マイニングと同じ種類の計算（SHA-256 二重ハッシュ）を Web Worker で繰り返し、スマホ・PCの性能、発熱、バッテリー消費を測るための単体HTMLページです。

- **実際のコインは採掘しません。** マイニングプールなど外部への通信は一切ありません。
- 開始前に同意チェックが必要で、いつでも停止できます。
- スレッド数、負荷率、難易度、自動停止を設定できます。
- Battery Status API（Android Chrome等）で電池消費を記録できます。

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages で公開できます。
